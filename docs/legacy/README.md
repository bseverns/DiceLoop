# Legacy Sketches (Do Not Flash On Stage)

This corner holds the crusty Arduino-era experiments that birthed DiceLoop. The
`rough.ino` sketch is here for archaeology and teaching moments only—you'll
learn where the chaos engine started, but it does **not** match the modern
PlatformIO firmware living under `src/`. Treat it like a zine photocopy: read
it, annotate it, but don't mistake it for the current build.
